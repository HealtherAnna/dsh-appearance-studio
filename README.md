# DSH 外观工作室

给 **DeepSeek Harness** 换外观：主题色、界面背景图、桌面与托盘图标，全部在设置里点几下完成。

装好之后，入口在 **设置 → 外观工作室**，和「插件市场」并排。

## 能做什么

### 🎨 换主题色

选一个颜色，界面里的链接、选中态、高亮、焦点环会自动跟着一起变，不用逐个去调。

内置 18 个常用预设色，也可以直接用取色盘挑任意颜色。改动**即时预览**，满意后保存。

### 🖼️ 放一张背景图

上传任意图片作为界面背景（支持 png / jpg / webp / gif / bmp），可以调**背景可见度**和**模糊**，并选择铺满裁切、完整显示或平铺。

背景图始终铺在最底层，**不会盖住任何文字或窗口**；设置、确认框这类弹窗保持实心，不受影响。

「背景可见度」控制的是**界面底色有多通透**：

| 背景可见度 | 效果 |
|---|---|
| **拉满 100%** | 界面底色全透，看到的就是**原图本身的颜色** |
| 70% 左右 | 背景明显，文字依然清晰（推荐） |
| 调低 | 底色变实、背景更淡、文字对比度更高 |

### 🖥️ 替换桌面与托盘图标

上传一张图，一次性替换：

- Windows **系统托盘**图标
- **任务栏 / 窗口**图标
- **桌面快捷方式**与开始菜单的图标

接受 `.ico` 或 `.png`。PNG 会自动打包成含 **16 / 24 / 32 / 48 / 64 / 128 / 256** 七档尺寸的 ICO，所以在小图标、任务栏、桌面等各个位置都清晰，不会被拉伸发虚。

原图标会自动备份，随时可以一键还原。

## 安装

| | |
|---|---|
| **GitHub 仓库** | <https://github.com/HealtherAnna/dsh-appearance-studio> |
| **npm 包名** | `dsh-appearance-studio` |

### 方式一：从 GitHub 安装（当前可用）

**1. 把仓库克隆到一个固定、以后不会移动的位置**

```bash
git clone https://github.com/HealtherAnna/dsh-appearance-studio.git
```

也可以直接下载 ZIP 解压。关键是这个目录之后别移动或删除——用软链方式安装时，移动了就得重新装一次。

> 要安装的是**包含 `package.json` 的那一层**，不要多套一层同名目录。

**2. 在 DSH 的任意会话里说一句**

> 帮我把 `<克隆目录的绝对路径>` 这个插件装上

**3. 重启客户端**

### 方式二：从 npm 安装

> ⚠️ **这个包目前尚未发布到 npm**。旧名 `dsh-skin-studio` 在 npm 上已被他人占用，因此改名为 `dsh-appearance-studio`；发布流程完成后即可使用下面两种方式。

Web 版：

```bash
dsh plugin --profile web add dsh-appearance-studio
```

桌面客户端：在任意会话里说一句

> 帮我把 `dsh-appearance-studio` 这个插件装上

> 命令行安装需要系统里有 `pnpm`；没有的话先执行 `npm install -g pnpm`。

### 关于桌面客户端

桌面客户端读取的是 `desktop` 配置档，命令行工具按设计不允许直接改它，所以桌面端统一用「在会话里说一句」的方式安装（客户端内置的插件管理器会处理）。

装完**重启一次客户端**，就能在设置里看到「外观工作室」。

> 重启后没看到入口？先确认插件确实安装成功，再重启一次 —— 客户端插件是在启动时装配的。

## 使用

打开 **设置 → 外观工作室**，里面有三个页签。

### 主题色

1. 勾选「启用自定义主题色」
2. 拖色盘，或点一个预设色块 —— 界面会即时预览
3. 点「**应用并保存**」

想恢复原样：取消勾选后再保存，或点「恢复默认」。

> 主要按钮会保持 DSH 原本的黑白设计。那是它的设计语言——按钮的底色和文字色是成对定义的，只改底色会让按钮文字失去对比度，所以主题色只作用于链接、高亮、状态色、焦点环这些强调色。

### 背景图

1. 点虚线框选图，或把图片直接拖进去
2. 调「背景可见度」（见上文表格）和「模糊」
3. 点「**应用并保存**」

不想要背景了，点「删除背景」。

### 图标

1. 点虚线框选图（`.ico` 或 `.png`）
2. 点「**应用到客户端**」
3. **重启客户端**，让托盘和窗口图标更新

桌面上的图标可能还需要按一下 `F5` 刷新桌面才更新（Windows 的图标缓存）。

想换回原来的图标，点「还原原图标」。

## 常见问题

**装好了，但「设置」里没有「外观工作室」？**

重启客户端。客户端插件是在启动时装配的，只刷新页面不够。

**托盘图标没变？**

1. 确认点过「应用到客户端」
2. 重启客户端
3. 还不变就重启一下 `explorer.exe`（或注销重登）—— Windows 会缓存托盘图标，这跟插件无关

**桌面上的图标没变？**

先按 `F5` 刷新桌面。如果仍不变，说明那个快捷方式不在标准位置（用户桌面 / 公共桌面 / 开始菜单），可以手动改：右键快捷方式 → 属性 → 更改图标。

**看不到背景图？**

- 把「背景可见度」调高
- 注意：**设置面板打开时看不到背景是正常的** —— 它有意保持实心，关掉面板看主界面

**背景图颜色比原图淡？**

把「背景可见度」拉满，界面底色就完全透明，显示的是原图本身的颜色。如果拉满后文字不好读，说明这张图对比度太高，建议换一张，或把可见度停在 70% 左右。

**DSH 升级后图标变回去了？**

DSH 升级会覆盖图标文件。重新点一次「应用到客户端」即可，**主题色和背景图不受影响**。

**改动没生效？**

- 主题色 / 背景图：保存后即时生效；个别区域没跟上就按 `Ctrl + F5` 刷新页面
- 图标：必须重启客户端

## 卸载

1. 在「设置 → 外观工作室 → 图标」里点「**还原原图标**」，恢复原始图标
2. 移除插件：
   - npm 安装的：`dsh plugin --profile web remove dsh-appearance-studio`
   - 本地目录安装的：在插件管理界面移除
3. 可选：删除数据目录 `%USERPROFILE%\.dsh\dsh-skin`，里面是你保存的设置、背景图和上传的图标
